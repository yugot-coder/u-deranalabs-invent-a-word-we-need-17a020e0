# Invent a Word We Need

One new English word, defined in a single clear line. The word names
the chair in every bedroom that holds clothes too clean to wash and
too worn to put away — a piece of furniture English never named.

> Chairdrobe (n.) the chair that holds clothes too clean to wash and too worn to put away.

## Run

```sh
python3 main.py
```

Writes the entry to `<MAKEFUN_OUTPUT_DIR>/entry.txt` (default
`/output/entry.txt`). Standard library only, deterministic, no network.
